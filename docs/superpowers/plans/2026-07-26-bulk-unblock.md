# 批量 IP 解封 Implementation Plan

**Goal:** 允许获授权用户批量解封，普通用户按成功 IP 消耗额度，sudo 用户不限额。

### Task 1: Helper 批量接口

- [ ] 先写 unittest：授权拒绝、sudo 多 IP 全部执行、普通用户额度耗尽停止、单 IP 失败隔离、来源透传。
- [ ] 新增严格解析的 `bulk-unblock --source <source> <ip>...`；限制请求 IP 数量，复用单 IP 解封编排。
- [ ] 返回每个 IP 的结果、汇总数量和未处理 IP；普通用户额度耗尽后停止。
- [ ] 运行完整 Python 测试与语法检查。

### Task 2: Cockpit 批量界面

- [ ] 先写前端契约测试：选择列、全选、批量命令和结果展示。
- [ ] 增加复选框、全选当前筛选结果、批量按钮和确认弹窗。
- [ ] 显示逐 IP 汇总和未处理数量；刷新后清空已处理选择。
- [ ] 运行完整测试、JS 语法和空白检查。

### Task 3: WSL 验证与说明

- [ ] 更新 README 的权限/额度/批量行为说明。
- [ ] 部署到 WSL，以 mxy 验证 helper 批量接口；使用保留测试地址并确保规则清理。
