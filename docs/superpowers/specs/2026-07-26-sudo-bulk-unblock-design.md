# sudo 批量解封设计

## 目标

允许所有获授权用户在 Cockpit 中多选 IP 并批量解封，保留每个 IP 和每个来源的独立结果。

## 权限与接口

`list` 返回 `can_bulk_unblock`，当用户通过当前 `access_mode` 授权时为 true。前端据此显示复选框、全选控件和批量按钮。

新增 helper 命令 `bulk-unblock --source <source> <ip>...`。后端再次验证授权、IP 数量和来源白名单；不依赖前端隐藏。

## 行为

批量操作按选定 IP 依次执行当前单 IP 解封编排。每个 IP 的 fail2ban/firewalld/UFW/iptables 来源结果独立返回；失败不影响后续 IP。sudo 用户不受每日额度限制；普通用户每成功解封一个 IP 消耗一次额度，额度耗尽后停止并返回已处理与未处理 IP。确认弹窗显示 IP 数量和来源。

## 前端

在获授权用户的表格中增加选择列和“全选当前筛选结果”。批量按钮仅在选中至少一项时可用。结果消息汇总成功、部分成功、失败与未处理数量，并保留详细结果。

## 验证

单元测试覆盖授权拒绝、sudo 与普通用户的额度行为、多 IP 结果隔离、来源透传和前端权限控制；在 WSL 以 mxy 实测批量界面与 helper。
