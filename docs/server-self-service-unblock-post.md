# 服务器自助解封功能介绍

如果你的访问 IP 被服务器防火墙或安全策略误封，可以使用服务器自助解封页面查看封禁状态并提交解封请求。系统会自动汇总 iptables、fail2ban、firewalld 与 UFW 中可识别的精确 IP 封禁记录，并显示封禁来源、规则详情和位置信息，便于确认当前 IP 是否确实被拦截。

## 使用方式

1. 先访问 `https://ip.ustc.edu.cn`，确认当前网络出口的公网 IP 地址。
2. 如果当前网络已经无法打开解封网站，请切换到其他网络访问，例如手机热点、校园网以外的网络、VPN、堡垒机或管理员提供的备用访问路径。
3. 打开管理员提供的 Cockpit 访问入口。
4. 使用自己的系统账号登录。
5. 在“IP 自助解封”页面查看封禁 IP、封禁来源和规则详情，确认列表中是否包含第 1 步查到的公网 IP。
6. 如果账号已被授权，点击对应 IP 的“解封”按钮并确认操作。

## 权限说明

- 已授权用户可以查看并解封 IP，普通用户按每日额度限制使用。
- 未授权用户可以按管理员配置只读查看封禁 IP，但解封按钮会置灰，无法提交解封。
- sudo 组用户不受每日额度限制。
- 每次成功解封都会写入审计日志和今日解封记录。

## 安全保护

本说明页建议设置为密码保护，仅提供给需要使用该功能的用户。不要在公开页面发布 Cockpit 管理入口、服务器地址、访问密码或可直接执行解封的链接。

真正的解封操作仍受以下机制保护：

- Cockpit 登录认证。
- `/etc/cockpit-ip-unblock.conf` 中的 `allowed_users` 授权列表。
- 普通用户每日解封额度。
- 后端 helper 对解封命令的固定参数校验。
- 系统审计日志记录。

如页面显示只能查看、无法点击解封，说明当前账号未被加入解封授权列表，请联系管理员处理。
